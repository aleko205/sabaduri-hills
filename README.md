# Sabaduri Hills — აღდგენილი საიტი

## გახსნა და გამოქვეყნება

## ვიზუალი და გალერეა
ქართული შრიფტი BPG Tech Caps Black ადგილობრივად იტვირთება მომხმარებლის მიერ მოწოდებული TTF-დან, როგორც ძველ HTML-ში. მთავარი სათაური ცენტრშია. გასუფთავებული ტყის ქავერი AI-ით რედაქტირებული დეკორატიული ფონი არის და ისტორიულ ორიგინალ ფოტოდ არ არის მიჩნეული.
გალერეას აქვს კარუსელი, ფოტოების გახსნა, ისრები, კლავიატურით გადართვა, მრიცხველი, გადიდება, მხარდაჭერის შემთხვევაში სრული ეკრანი და ბმულის კოპირება. მთავარ გალერეაში 5-წამიანი ავტომატიკა შეჩერებადია; reduced-motion-ისას გამორთულია.
